🛡 SurakshaEdge — Operator Guide

📢 Understanding Alerts

  • ALERT = kinematic struggle (K_t≥0.62 for 0.4 s) AND audio scream (S_t≥0.70 for 0.5 s) detected simultaneously within a 1.5 s gate window. Highest confidence.
  • ADVISORY = only one signal detected (kinematic OR audio). Investigate but not confirmed assault.

📊 Score Meanings

  • K_t (0–1) — Kinematic score from pose/motion model. ≥0.62 triggers kinematic flag.
  • S_t (0–1) — Audio score from CNN or energy fallback. ≥0.70 triggers audio flag.
  • dt_s — Time gap between K and S detections (should be <1.5 s for ALERT).
  • ALERT fires only when BOTH flags are active within the gate window.

🗺 Map Zones

  • Blue semi-transparent polygon = monitored campus perimeter (GNIOT, Greater Noida).
  • Camera pins: grey = idle, orange = advisory, red = active alert (pulses).
  • Alert pins auto-remove after 15 s; camera icon resets to idle.

⚠ Audio Mode Warning

If the ENERGY FALLBACK badge appears, the MFCC-CNN model is not loaded. In fallback mode, S_t detects any loud sound — not specifically screams. False positives increase significantly. Load models/audio_cnn.onnx for true scream detection.

🔒 Privacy

  • No video stored persistently. Only a 5-second RAM ring buffer is maintained.
  • An AES-256-GCM encrypted short clip is saved only on confirmed ALERT events.
  • All data stays on-device (edge processing). No cloud upload. No face recognition.
